# Product Breakdown — sequence-extensions-gui

Current-state record for the local web GUI that previews and runs `sequence_extensions` flows.

## The Eight Layers

- `00-intent/` — why does the project exist, who is it for?
- `01-product/` — what is delivered, what is out of scope?
- `02-architecture/` — how are deliverables, evidence, and work organized?
- `03-implementation/` — with what concrete assets is it realized?
- `04-verification/` — how do we know it satisfies the requirements?
- `05-operation/` — how do authors run, maintain, release?
- `06-evolution/` — what work is open: improvements, investigations, plans?
- `07-review/` — how are the definition and the implementation scrutinized?
- the decision archive — dated history, read via `pb archive`, never browsed

## Boundary Rule

The breakdown is the source of truth: a document's home is the layer whose
question it answers, and information flows downward only. State lives in leaves,
history in the archive, open work in `06-evolution/`; review routes findings back.

## Excludes

- Implementation narrative (`docs/architecture.md`) and the upstream engine's record.
